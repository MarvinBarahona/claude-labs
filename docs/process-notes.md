- **`no-multiline-comments` hook regex false positive** — `.claude/hooks/check-multiline-comments.py`'s `BLOCK_COMMENT_RE` (`/\*\*?.*?\*/`, `re.S`) matches across unrelated string literals, not just real comments: `frontend/eslint.config.js`'s two glob strings `'**/*.ts'` and `'**/*.html'` each contain a bare `/*`/`*/` substring, so the regex spans from the first glob's `/*` all the way to the second glob's `*/`, flagging the ~28 lines between them as one giant multi-line block comment even though no comment exists there at all. Found while auditing the repo for latent hook violations; the file was left untouched (there's nothing to condense) but a future edit to `eslint.config.js` — or any other file with a `/*`...`*/`-spanning pair of string literals — will trip this same false positive and block unrelated work. Worth tightening the regex to not match `/*`/`*/` sequences inside string literals.
